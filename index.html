CASE STUDY 01 // MICROSERVICES & CONCURRENCY
DWG NO: BP-MS-2026 COMPLETED ARCHITECTURE

BidPulse: Real-Time Auction Platform

Autonomous Microservices · Atomic Concurrency via Redis Lua · WebSocket Push

ENGINEERING CHALLENGE: HIGH-CONCURRENCY RACE CONDITIONS

When multiple users bid concurrently within milliseconds, naive database queries produce dirty reads and lost updates. Relational locks at scale choke the throughput of active auctions.

Engineered an atomic concurrency barrier using an in-memory Redis Lua script (EVALSHA). The script checks seller-approved bidder sets and verifies that the incoming bid strictly exceeds the current high bid as a single atomic operation before committing to PostgreSQL. Split into independent AuthService and BidService communicating over HTTP.

  • Dual Autonomous Services: AuthService (:4000) for identity/OAuth and BidService (:3000) for domain logic.
  • Real-Time Broadcast: Socket.IO auction rooms push live price changes instantly without client polling.
  • Post-Sale Workflow: Mandatory courier/shipment tracking proof upload required within fixed windows.
  • Seller Reputation: Wilson score lower bound confidence rating prevents review skewing.
  • Test Payments: Integrated Razorpay test mode with HMAC-SHA256 signature verification.

CASE STUDY 02 // AIR-GAPPED AI & VECTOR RETRIEVAL
DWG NO: RAG-VEC-2026 COMPLETED ARCHITECTURE

Offline RAG System for Technical Documents

Structure-Aware Chunking · Dense Semantic Embeddings · FAISS Vector Index

ENGINEERING CHALLENGE: AIR-GAPPED PRIVACY & HALLUCINATIONS

Enterprise and defense technical documents cannot be dispatched to cloud APIs. Naive fixed-length character chunking fragments syntax, destroys tabular data, and generates hallucinations.

Built a fully offline Retrieval-Augmented Generation engine powered by FastAPI, FAISS, and Sentence Transformers. The parser parses document structure (hierarchical headers and sections) before encoding into 384-dimensional dense vectors. Context injection forces local LLM inference to answer strictly from retrieved passages.

  • Zero Internet Dependency: Runs completely within closed, private network environments without external API costs.
  • Structure-Aware Chunking: Preserves section context from PDF/DOCX manuals rather than splitting on arbitrary word limits.
  • FAISS Vector Search: Millisecond L2 / cosine similarity retrieval across thousands of document chunks.
  • Strict Context Grounding: Injects top-k passages with explicit prompts to eliminate synthetic hallucinations.
  • REST Endpoints: Clean FastAPI interface for document ingestion, index recreation, and query responses.

CASE STUDY 04 // SENSOR PERCEPTION & SIGNAL PROCESSING
DWG NO: MMW-RAD-2026 MISTRAL SOLUTIONS INTERNSHIP

TI AWR1843 mmWave Radar Aerial Classification

77GHz FMCW Radar · Range/Doppler FFT · STFT Micro-Doppler Spectrograms

ENGINEERING CHALLENGE: DRONE VS BIRD LOW-ALTITUDE DISCRIMINATION

In perimeter surveillance, optical sensors fail in low light or fog. Radar backscatter from small drones and birds shares similar radar cross-sections (RCS), requiring micro-Doppler spectral analysis.

Internship research at Mistral Solutions. Configured and flashed Texas Instruments AWR1843 77GHz mmWave hardware. Parsed raw UART ADC frames, executed 2D FFTs (Range and Doppler), and computed Short-Time Fourier Transform (STFT) spectrograms to isolate micro-Doppler blade rotation signatures. Trained a Random Forest baseline achieving 92.9% accuracy and 0.974 ROC-AUC, transitioning toward CNN and CNN-LSTM architectures.

  • Hardware Profile Configuration: Texas Instruments AWR1843 FMCW chirp configuration and UniFlash firmware deployment.
  • UART / TLV Parser: Ingested high-throughput binary frames containing detected point clouds and raw ADC samples.
  • Signal Processing Pipeline: Range-FFT, Doppler-FFT, CA-CFAR target detection, and STFT spectrogram extraction.
  • Machine Learning Baseline: 92.9% classification accuracy with 0.974 ROC-AUC discriminating rotating drone blades from bird wing flap kinematics.
